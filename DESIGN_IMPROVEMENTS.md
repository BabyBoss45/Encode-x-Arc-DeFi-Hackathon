## 💡 Технические детали

### Использованные техники:
- CSS Grid и Flexbox для layout
- CSS Custom Properties (переменные)
- Градиенты и backdrop-filter
- CSS Transitions и Transforms
- Pseudo-elements (::before, ::after)
- Sticky positioning

### Производительность:
- Использование `transform` вместо `position` для анимаций
- `will-change` для оптимизации анимаций
- Минимизация repaints и reflows
