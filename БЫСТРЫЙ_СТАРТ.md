# ⚡ Быстрый старт (БЕЗ PostgreSQL)

## Самый простой способ - используйте SQLite

SQLite - это встроенная база данных, не требует установки!

## Шаг 1: Установите зависимости

```bash
# Backend зависимости
cd backend
pip3 install -r requirements.txt

# Frontend зависимости (если еще не установлены)
cd ../src
pip3 install fastapi uvicorn jinja2 python-multipart requests
```

## Шаг 2: Создайте .env файл для backend

```bash
cd backend
cat > .env << 'EOF'
DATABASE_URL=sqlite:///./bossboard.db
JWT_SECRET_KEY=my-secret-key-change-in-production
CIRCLE_API_KEY=test-key
CIRCLE_BASE_URL=https://api.circle.com/v1
EOF
```

**Примечание**: SQLite не требует настройки DATABASE_URL - он создаст файл `bossboard.db` автоматически!

## Шаг 3: Запустите Backend

```bash
cd backend
python3 main.py
```

Должно появиться:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

**Оставьте этот терминал открытым!**

## Шаг 4: Запустите Frontend (в НОВОМ терминале)

Откройте новый терминал:

```bash
cd src
python3 frontend.py
```

Должно появиться:
```
🚀 Starting frontend on http://localhost:8001
```

## Шаг 5: Откройте в браузере

Откройте: **http://localhost:8001/login**

## Готово! 🎉

Теперь вы можете:
1. Зарегистрироваться
2. Войти в систему
3. Использовать конструктор

## Что происходит:

- **Backend** (порт 8000) - обрабатывает запросы, сохраняет в базу данных
- **Frontend** (порт 8001) - показывает страницы, отправляет запросы в backend
- **База данных** - файл `bossboard.db` в папке `backend/` (создается автоматически)

## Если нужен PostgreSQL (позже):

1. Установите PostgreSQL
2. Создайте базу: `createdb bossboard`
3. Измените в `.env`: `DATABASE_URL=postgresql://postgres:password@localhost/bossboard`

Но для начала SQLite достаточно!
