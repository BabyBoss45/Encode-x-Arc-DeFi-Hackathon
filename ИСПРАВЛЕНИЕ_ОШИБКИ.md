# 🔧 Исправление ошибки "command not found: pip"

На Mac часто нужно использовать `pip3` вместо `pip`.

## Решение 1: Используйте pip3 (самое простое)

Вместо:
```bash
pip install fastapi uvicorn jinja2 python-multipart
```

Попробуйте:
```bash
pip3 install fastapi uvicorn jinja2 python-multipart
```

---

## Решение 2: Используйте python3 -m pip

```bash
python3 -m pip install fastapi uvicorn jinja2 python-multipart
```

---

## Решение 3: Проверьте установлен ли Python

Проверьте версию Python:
```bash
python3 --version
```

Если Python не установлен, установите его:
```bash
brew install python3
```

Или скачайте с официального сайта: https://www.python.org/downloads/

---

## Решение 4: Используйте виртуальное окружение (рекомендуется)

```bash
# Создайте виртуальное окружение
python3 -m venv venv

# Активируйте его
source venv/bin/activate

# Теперь pip будет работать
pip install fastapi uvicorn jinja2 python-multipart
```

---

## После установки зависимостей:

Запустите фронтенд:
```bash
python3 run_frontend.py
```

Или:
```bash
python3 src/frontend.py
```
