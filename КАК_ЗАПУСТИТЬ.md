# 🚀 Как запустить фронтенд - ПРОСТАЯ ИНСТРУКЦИЯ

## Вариант 1: Самый простой (рекомендуется)

### Шаг 1: Установите зависимости
Откройте терминал в папке проекта и выполните:

```bash
pip install fastapi uvicorn jinja2 python-multipart
```

### Шаг 2: Запустите скрипт
В той же папке выполните:

```bash
python run_frontend.py
```

Готово! Откройте браузер: **http://localhost:8001/login**

---

## Вариант 2: Вручную

### Шаг 1: Установите зависимости
```bash
pip install fastapi uvicorn jinja2 python-multipart
```

### Шаг 2: Перейдите в папку src
```bash
cd src
```

### Шаг 3: Запустите файл frontend.py
```bash
python frontend.py
```

Или через uvicorn:
```bash
uvicorn frontend:app --host 0.0.0.0 --port 8001 --reload
```

---

## 📁 Какой файл открывать?

**НЕ нужно открывать файлы в редакторе для запуска!**

Просто запустите в терминале:
- `python run_frontend.py` (из корневой папки проекта)
- ИЛИ `python src/frontend.py` (из корневой папки проекта)
- ИЛИ `cd src && python frontend.py` (из корневой папки проекта)

---

## 🌐 Что делать после запуска?

1. Откройте браузер (Chrome, Firefox, Safari - любой)
2. Введите адрес: **http://localhost:8001/login**
3. Вы увидите страницу входа!

---

## ✅ Проверка что работает:

1. Откройте: http://localhost:8001/signup
2. Зарегистрируйтесь (например: username: `test`, password: `123`)
3. Откройте: http://localhost:8001/login
4. Войдите с вашими данными
5. Вы попадете на Dashboard!

---

## ❌ Если не работает:

### Ошибка "ModuleNotFoundError"
Установите зависимости:
```bash
pip install fastapi uvicorn jinja2 python-multipart
```

### Ошибка "Address already in use"
Порт 8001 занят. Измените порт в файле `src/frontend.py` (последняя строка):
```python
uvicorn.run(app, host="0.0.0.0", port=8002)  # Измените на 8002
```

### Не знаете как открыть терминал?
- **Mac**: Нажмите Cmd+Space, введите "Terminal"
- **Windows**: Нажмите Win+R, введите "cmd" или "powershell"
- **Linux**: Ctrl+Alt+T
