# 🚀 Миграция на PostgreSQL и доступ с разных устройств

## Быстрый старт

### 1. Установите PostgreSQL
- Windows: https://www.postgresql.org/download/windows/
- Mac: `brew install postgresql@14 && brew services start postgresql@14`
- Linux: `sudo apt-get install postgresql`

### 2. Создайте базу данных
```bash
psql -U postgres
CREATE DATABASE bossboard;
\q
```

### 3. Установите драйвер
```powershell
cd backend
py -m pip install psycopg2-binary
```

### 4. Настройте .env файл
Создайте `backend/.env`:
```env
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost/bossboard
JWT_SECRET_KEY=your-secret-key
CIRCLE_API_KEY=test-key
CIRCLE_BASE_URL=https://api.circle.com/v1

# Для доступа с разных устройств (разрешить все источники):
CORS_ORIGINS=*
```

### 5. Узнайте ваш IP адрес
```powershell
# Windows:
ipconfig
# Найдите IPv4 Address (например, 192.168.1.100)
```

### 6. Запустите backend
```powershell
cd backend
py main.py
```

### 7. Запустите frontend с вашим IP
```powershell
# Замените 192.168.1.100 на ваш IP:
$env:API_BASE_URL="http://192.168.1.100:8000/api"
cd src
py frontend.py
```

### 8. Откройте с любого устройства
- **С телефона/планшета:** `http://ВАШ_IP:8001/login`
- **С другого компьютера:** `http://ВАШ_IP:8001/login`

## Настройка файрвола (Windows)

1. Откройте "Брандмауэр Защитника Windows"
2. "Дополнительные параметры" → "Правила для входящих подключений"
3. "Создать правило" → "Порт" → TCP → Порты: 8000, 8001 → "Разрешить подключение"

## Важно для безопасности

⚠️ `CORS_ORIGINS=*` разрешает доступ со всех источников - используйте только для разработки!

Для продакшена укажите конкретные адреса:
```env
CORS_ORIGINS=http://192.168.1.100:8001,http://localhost:8001
```
