# 🌐 Запуск с доступом из сети

## Ваш IP адрес: **192.168.6.29**

## Быстрый запуск (2 способа):

### Способ 1: Использовать готовые скрипты (рекомендуется)

**Терминал 1 - Backend:**
```powershell
.\start_backend_network.ps1
```

**Терминал 2 - Frontend:**
```powershell
.\start_with_network_access.ps1
```

### Способ 2: Вручную

**Терминал 1 - Backend:**
```powershell
cd backend

# Убедитесь, что в .env есть:
# CORS_ORIGINS=*

py main.py
```

**Терминал 2 - Frontend:**
```powershell
$env:API_BASE_URL="http://192.168.6.29:8000/api"
cd src
py frontend.py
```

## Доступ с других устройств:

### С телефона/планшета:
1. Убедитесь, что устройство подключено к той же Wi-Fi сети
2. Откройте браузер и перейдите:
   ```
   http://192.168.6.29:8001/login
   ```

### С другого компьютера:
1. Убедитесь, что компьютер в той же сети
2. Откройте браузер:
   ```
   http://192.168.6.29:8001/login
   ```

## Настройка файрвола (если не работает):

### Windows:
1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. "Правила для входящих подключений" → "Создать правило"
4. Выберите "Порт" → "TCP"
5. Укажите порты: **8000** и **8001**
6. Выберите "Разрешить подключение"
7. Примените для всех профилей

### Или через PowerShell (от администратора):
```powershell
New-NetFirewallRule -DisplayName "BossBoard Backend" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "BossBoard Frontend" -Direction Inbound -LocalPort 8001 -Protocol TCP -Action Allow
```

## Проверка:

1. **Backend API:** http://192.168.6.29:8000/docs
2. **Frontend:** http://192.168.6.29:8001/login
3. **Локально:** http://localhost:8001/login (тоже должно работать)

## Если не работает:

1. **Проверьте, что оба устройства в одной сети:**
   - Устройство должно быть в сети 192.168.4.x или 192.168.6.x

2. **Проверьте файрвол:**
   - Убедитесь, что порты 8000 и 8001 открыты

3. **Проверьте, что серверы запущены:**
   ```powershell
   netstat -ano | findstr ":8000"
   netstat -ano | findstr ":8001"
   ```

4. **Проверьте CORS настройки:**
   - В `backend/.env` должно быть: `CORS_ORIGINS=*`

## Важно:

⚠️ `CORS_ORIGINS=*` разрешает доступ со всех источников - используйте только в локальной сети!

Для продакшена укажите конкретные адреса в `backend/.env`:
```
CORS_ORIGINS=http://192.168.6.29:8001,http://localhost:8001
```
