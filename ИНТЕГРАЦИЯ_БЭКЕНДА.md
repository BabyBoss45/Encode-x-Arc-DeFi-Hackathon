# ✅ Интеграция Frontend с Backend API

## Проблема решена!

Frontend теперь подключен к Backend API. Данные сохраняются в базе данных и не теряются при перезапуске!

## Как это работает:

### 1. **Автоматическое определение Backend**
- Frontend проверяет доступность backend при каждом запросе
- Если backend доступен → использует API (данные в БД)
- Если backend недоступен → использует fallback (in-memory, только для тестирования)

### 2. **Аутентификация через JWT**
- При регистрации/логине получается JWT токен
- Токен сохраняется в cookie
- Все запросы к API используют токен для авторизации

### 3. **Сохранение данных**
- Все данные сохраняются в PostgreSQL/SQLite через API
- Данные привязаны к пользователю (company_id)
- Данные не теряются при перезапуске

## Как запустить:

### Шаг 1: Запустите Backend

```bash
cd backend
python3 main.py
```

Должно появиться:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### Шаг 2: Запустите Frontend

В **НОВОМ** терминале:

```bash
cd src
python3 frontend.py
```

Должно появиться:
```
🚀 Starting ARC budget frontend on http://localhost:8001
💡 Make sure backend is running on http://localhost:8000 for data persistence
```

### Шаг 3: Откройте в браузере

**http://localhost:8001/login**

## Что изменилось:

✅ **Регистрация** → сохраняется в БД через API  
✅ **Логин** → проверка через API, получение JWT токена  
✅ **Создание департаментов** → сохраняется в БД  
✅ **Добавление работников** → сохраняется в БД  
✅ **Добавление расходов** → сохраняется в БД  
✅ **Добавление доходов** → сохраняется в БД  
✅ **Dashboard** → данные из БД через API  

## Важно:

- **Backend должен быть запущен** для сохранения данных
- Если backend не запущен, frontend будет работать в режиме fallback (данные теряются при перезапуске)
- JWT токен хранится в cookie и автоматически используется для всех запросов

## Проверка работы:

1. Зарегистрируйтесь
2. Создайте департамент
3. Добавьте работника
4. Перезапустите frontend
5. Войдите снова → **данные должны сохраниться!** ✅

Теперь данные не теряются! 🎉
