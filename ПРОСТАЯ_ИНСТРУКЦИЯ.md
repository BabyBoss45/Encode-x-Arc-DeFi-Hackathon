# 🚀 Простая инструкция по запуску

## Что такое PostgreSQL?

PostgreSQL - это база данных (хранилище данных). Нам она нужна, чтобы сохранять информацию о пользователях, работниках, департаментах и т.д.

## Вариант 1: Установка PostgreSQL (если еще не установлен)

### На Mac:
```bash
# Установка через Homebrew
brew install postgresql@14

# Запуск PostgreSQL
brew services start postgresql@14
```

### На Windows:
1. Скачайте с официального сайта: https://www.postgresql.org/download/windows/
2. Установите (используйте стандартные настройки)
3. Запомните пароль для пользователя `postgres`

### На Linux (Ubuntu/Debian):
```bash
sudo apt-get update
sudo apt-get install postgresql postgresql-contrib
sudo systemctl start postgresql
```

## Вариант 2: Использовать SQLite (проще, без установки PostgreSQL)

Если не хотите устанавливать PostgreSQL, можно использовать SQLite (встроенная база данных).

## Создание базы данных

### Если используете PostgreSQL:

```bash
# Создать базу данных
createdb bossboard

# Или через psql:
psql -U postgres
CREATE DATABASE bossboard;
\q
```

### Если используете SQLite (проще):

Не нужно ничего создавать! SQLite создаст файл автоматически.

## Пошаговая инструкция по запуску

### Шаг 1: Проверьте, что PostgreSQL установлен

```bash
# Проверка версии
psql --version

# Если команда не найдена, установите PostgreSQL (см. выше)
```

### Шаг 2: Создайте базу данных

```bash
createdb bossboard
```

Если выдает ошибку "command not found", попробуйте:
```bash
# На Mac/Linux
/usr/local/bin/createdb bossboard

# Или через psql
psql -U postgres -c "CREATE DATABASE bossboard;"
```

### Шаг 3: Настройте Backend

```bash
# Перейдите в папку backend
cd backend

# Установите зависимости
pip3 install -r requirements.txt
```

### Шаг 4: Создайте файл .env

```bash
cd backend
cat > .env << 'EOF'
DATABASE_URL=postgresql://postgres:password@localhost/bossboard
JWT_SECRET_KEY=my-secret-key-12345
CIRCLE_API_KEY=your-circle-api-key-here
CIRCLE_BASE_URL=https://api.circle.com/v1
EOF
```

**ВАЖНО**: Замените:
- `password` на ваш пароль PostgreSQL (если установили)
- `your-circle-api-key-here` на ваш реальный Circle API ключ (пока можно оставить как есть для теста)

### Шаг 5: Запустите Backend

```bash
cd backend
python3 main.py
```

Вы должны увидеть:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### Шаг 6: Запустите Frontend (в новом терминале)

```bash
cd src
python3 frontend.py
```

Вы должны увидеть:
```
🚀 Starting frontend on http://localhost:8001
```

### Шаг 7: Откройте в браузере

Откройте: **http://localhost:8001/login**

## Если PostgreSQL не работает

### Вариант A: Используйте SQLite (проще)

Измените в `backend/src/database.py`:

```python
# Было:
DATABASE_URL = os.getenv("DATABASE_URL", "postgresql://user:password@localhost/bossboard")

# Стало:
DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./bossboard.db")
```

И в `backend/src/models.py` добавьте в начало:
```python
from sqlalchemy import create_engine
# Для SQLite нужно добавить check_same_thread=False
```

### Вариант B: Используйте Docker (если установлен Docker)

```bash
# Запустить PostgreSQL в Docker
docker run --name bossboard-db \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=bossboard \
  -p 5432:5432 \
  -d postgres

# Теперь используйте:
DATABASE_URL=postgresql://postgres:password@localhost/bossboard
```

## Проверка что все работает

1. Backend работает: откройте http://localhost:8000/docs
2. Frontend работает: откройте http://localhost:8001/login
3. База данных работает: backend должен запуститься без ошибок

## Частые проблемы

### Ошибка: "could not connect to server"
- PostgreSQL не запущен: `brew services start postgresql` (Mac) или `sudo systemctl start postgresql` (Linux)

### Ошибка: "password authentication failed"
- Проверьте пароль в `.env` файле
- Или создайте пользователя: `createuser -s postgres`

### Ошибка: "database does not exist"
- Создайте базу: `createdb bossboard`

## Быстрый старт (минимальная настройка)

Если хотите быстро протестировать без PostgreSQL:

1. Используйте SQLite (см. Вариант A выше)
2. Запустите только frontend (он работает без backend, но данные не сохранятся)

```bash
cd src
python3 frontend.py
```
