# Простой фронтенд на Python для BossBoard

Это простой фронтенд на Python с использованием FastAPI. Начинаем с Login и Sign Up страниц.

## Как запустить:

### 1. Установите зависимости:

```bash
pip install fastapi uvicorn jinja2 python-multipart
```

### 2. Запустите фронтенд:

```bash
cd src
python frontend.py
```

Или через uvicorn:

```bash
cd src
uvicorn frontend:app --host 0.0.0.0 --port 8001
```

### 3. Откройте в браузере:

```
http://localhost:8001/login
```

## Структура файлов:

```
src/
├── frontend.py          # Главный файл с FastAPI приложением
├── templates/           # HTML шаблоны
│   ├── login.html       # Страница входа
│   ├── signup.html      # Страница регистрации
│   └── dashboard.html   # Главная страница (пока заглушка)
└── static/              # CSS и другие статические файлы
    └── style.css        # Стили
```
