# ✅ Все готово! Как запустить:

## Проблема решена!

Я убрал `psycopg2-binary` (он нужен только для PostgreSQL) и обновил зависимости. Теперь используется **SQLite** - не нужно устанавливать PostgreSQL!

## Запуск (2 терминала):

### Терминал 1 - Backend API:

```bash
cd backend
python3 main.py
```

Должно появиться:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

**Оставьте этот терминал открытым!**

### Терминал 2 - Frontend:

Откройте **НОВЫЙ** терминал:

```bash
cd src
python3 frontend.py
```

Должно появиться:
```
🚀 Starting frontend on http://localhost:8001
```

## Откройте в браузере:

**http://localhost:8001/login**

## Что было исправлено:

1. ✅ Убрал `psycopg2-binary` (не нужен для SQLite)
2. ✅ Обновил версии зависимостей
3. ✅ Создал `.env` файл с настройками SQLite
4. ✅ База данных создастся автоматически (файл `bossboard.db`)

## Если backend не запускается:

Проверьте ошибки в терминале. Возможные проблемы:

1. **Порт 8000 занят**: Измените порт в `backend/main.py`
2. **Модули не найдены**: Установите зависимости: `pip3 install -r backend/requirements.txt`
3. **Ошибка импорта**: Проверьте, что все файлы на месте в `backend/src/`

## Структура:

- **Backend** (порт 8000) - API с базой данных
- **Frontend** (порт 8001) - Веб-интерфейс
- **База данных** - файл `backend/bossboard.db` (создается автоматически)

Готово к использованию! 🚀
